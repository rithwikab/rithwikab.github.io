Problem

AI agents and LLM apps send the same kinds of structured data to the model on every request: tool definitions, JSON results and schemas. Much of it is repeated structure, like the same keys over and over, long descriptions and whitespace. Developers pay for all of it, per token, on every call.

  • Cost grows with usage. The more successful the product, the bigger the bill for data the model barely needs.
  • Context fills up. Verbose tool data crowds out the information that actually helps the model answer.
  • Manual fixes don’t last. Hand-trimming prompts works until the next schema change quietly undoes it.

Insight

The waste is in the structure, and structure is predictable. So it can be compressed automatically at the one point every request passes through: the boundary between the app and the model.

Goals and non-goals

Goals

  1. Substantially reduce tokens for structured payloads.
  2. Keep adoption friction low: install from npm and use it as an SDK or through an MCP proxy.
  3. License the Pro tier with keys that verify offline and can still be revoked.

Not in v1

  • Compressing free-form prose
  • Routing between models or acting as an LLM gateway
  • Hosting or fine-tuning models

Key decisions and trade-offs

Compress at the boundary, not in the app
Sitting between the app and the model means developers don’t touch their tools or prompts. Trade-off: the SDK has to understand many payload shapes instead of one.
Two ways in: SDK and MCP proxy
The SDK suits teams calling models directly. The proxy suits teams already on MCP who want zero code changes. Offering both widens the funnel at the cost of two surfaces to maintain.
Keys that verify offline
Cryptographically signed keys are checked locally, so there’s no network call and no added latency. Trade-off: an offline check can’t see a revoked key on its own, so a separate real-time revocation check covers that gap.
Free package, paid Pro tier
A free npm package earns adoption and trust. Pro features carry the revenue.

Technical design

Client appSDK: compressionMCP proxyLLM API
  • SDK: TypeScript package on npm. Compresses structured payloads before they’re sent to the model.
  • MCP proxy: sits in front of MCP tool traffic and applies the same compression, so existing MCP setups need no code changes.
  • Licensing: signed keys verified locally with a public key, plus a real-time revocation check.
  • Demo: a React dashboard on Vercel that shows token usage before and after compression.
